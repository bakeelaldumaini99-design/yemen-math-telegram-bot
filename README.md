# بوت الرياضيات الذكي — الصف الثالث الثانوي (اليمن) 📚

بوت تيليجرام تعليمي متخصص في الرياضيات للصف الثالث الثانوي، يعمل **بنظام ذكاء محلي مستقل**
بدون أي API خارجي للذكاء الاصطناعي — قاعدة بيانات محلية + محرك رياضيات + محرك فيزياء + معالجة عربية.

## المزايا الرئيسية

- **واجهة عربية بسيطة**: الطالب يكتب سؤاله مباشرة دون قوائم أو اختيارات
- **محرك رياضيات متكامل (SymPy)**: عمليات حسابية، معادلات، مشتقات، تكامل (محدد وغير محدد)، نهايات، هندسة
- **محرك فيزياء**: 12 قانونًا جاهزًا (أوم، نيوتن، طاقة، شغل، قدرة، كثافة...)
- **تصنيف تلقائي للمادة**: رياضيات / أحياء / فيزياء / كيمياء / لغة عربية / معلومات عامة
- **قاعدة بيانات تعليمية** (`subjects_db.json`) قابلة للتوسيع — 51 سؤالًا جاهزًا
- **تواصل ذكي**: تحيات، أسئلة عامة، تعريف بالبوت والأستاذ والقناة، تسامح مع الأخطاء الإملائية
- **لوحة تحكم كاملة للمشرف**: متابعة مباشرة لكل المحادثات + رد مباشر على الطلاب بهوية "إدارة البوت"

## التشغيل

```bash
pip install -r requirements.txt
set TELEGRAM_BOT_TOKEN=توكن_البوت
set TELEGRAM_PROXY=socks5://127.0.0.1:7897   # ضروري في اليمن
python math_bot.py
```

أو انقر نقرًا مزدوجًا على `run.bat` بعد تعبئة التوكن (ويندوز).

## أوامر المشرف

| الأمر | الوظيفة |
|------|---------|
| `/addadmin` `/removeadmin` `/admins` | إدارة المشرفين |
| `/stats` | الإحصائيات والحالة |
| `/chats [n]` | آخر المحادثات المسجلة |
| `/stop` `/run` | إيقاف/تشغيل رد البوت |
| `/setwelcome` `/setchannel` | تعديل الترحيب ورابط القناة |
| `/addqa` | إضافة سؤال وجواب لقاعدة البيانات |
| `/subjectsqa` | محتويات القاعدة حسب المادة |

## بنية المشروع

```
math_bot.py        # الكود الرئيسي (البوت + المحركات + لوحة التحكم)
subjects_db.json   # قاعدة البيانات التعليمية (قابلة للتوسيع)
run.bat            # تشغيل سريع لويندوز
data/              # بيانات التشغيل (لا تُرفع — مستبعدة في .gitignore)
```

## ملاحظات

- الإجابات بقالب موحد: المعطيات ← القانون ← النتيجة النهائية
- توكن البوت ومعرفات المشرفين تُضبط عبر متغيرات البيئة ولا تُخزن في الكود
- نظام الرد المباشر يخفي هوية المشرف عن الطالب (يظهر كـ"إدارة بوت الرياضيات")
